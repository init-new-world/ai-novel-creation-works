# AI Novel Collection / AI 小说合集

A repository of novels created or co-created by AI. Each work is stored as its own entry so readers and editors can browse, review, and version novels independently.  
一个由 AI 创作或与 AI 协作创作的小说集合库。每部作品作为独立条目存放，便于阅读、审阅与版本管理。

## Purpose / 目的
- Collect finished and in-progress novels generated with AI by me.  
    收集本人由 AI 生成的已完成与进行中的小说。
- Keep each novel self-contained with text, metadata, and assets.  
    让每部小说包含文本、元数据与配套资源，便于管理与发布。
- Make provenance clear: mark AI-generated content and include attribution or source notes.  
    明确来源：标注 AI 生成内容并包含必要的归因或来源说明。

## Repository structure (recommended) / 仓库结构（推荐）
- README.md — this file / 本文件  
- works — 小说文件夹
  - <novel_name> — the novel name / 小说名字
    - zh_CN.md — A novel created by me with the participation of artificial intelligence / 由本人创作使用人工智能参与的小说
    - en_US.md — The novel created by me with the participation of artificial intelligence and translated into English by artificial intelligence / 由本人创作使用人工智能参与的小说并由人工智能翻译来的英文版
- LICENSE — project license / 项目许可

## Authorship / 作者声明
